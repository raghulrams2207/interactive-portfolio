# 🚀 Interactive Portfolio Website

A modern, responsive, and interactive personal portfolio website built using **HTML5, CSS3, and JavaScript**. This project focuses on semantic HTML structure, web accessibility, responsive UI/UX, and search engine optimization (SEO).

Developed as part of my Web Development learning journey and internship at **Thiranex EduTech LLP**.

## ✨ Features

- **Modern UI/UX:** Clean, professional design with smooth transitions and interactive elements.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Multi-Page Navigation:** Dedicated Home, About, Projects, and Contact pages.
- **Dark/Light Mode:** Switch between themes for a personalized viewing experience.
- **Interactive Project Gallery:** Search projects and filter them by category.
- **Dynamic User Interface:** Scroll progress indicator, back-to-top button, and subtle reveal animations.
- **Accessible Contact Form:** Form labels, validation, and user feedback.
- **Semantic HTML5:** Proper use of semantic elements for meaningful page structure.
- **Web Accessibility:** Keyboard navigation, visible focus states, descriptive image alternatives, and reduced-motion support.
- **SEO Optimization:** Page-specific titles, meta descriptions, and structured navigation.
- **Clean Code:** Organized HTML, CSS, and JavaScript files.

## ♿ Accessibility

Accessibility is a core focus of this project.

- Semantic HTML5 landmarks.
- Keyboard-accessible interactive elements.
- Visible keyboard focus indicators.
- Meaningful alternative text for informative images.
- Accessible form labels and validation messages.
- Appropriate ARIA attributes where necessary.
- Support for reduced-motion preferences.
- Responsive layouts and readable content.

The project aims to follow **WCAG 2.2 Level AA principles**. Accessibility compliance and audit scores should be verified through testing.

## ⚙️ Installation and Setup

### Prerequisites

- [Visual Studio Code](https://code.visualstudio.com/)
- [Git](https://git-scm.com/)
- A modern web browser.
- The VS Code Live Server extension.

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/raghulrams2207/interactive-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd interactive-portfolio
```

**3. Open the project in VS Code**

```bash
code .
```

**4. Start the website**

Install the Live Server extension if necessary. Open `index.html`, right-click, and select **Open with Live Server**.

The website should open in your default browser.

## 🧪 Testing

Test the website using the following tools:

- **Google Lighthouse:** Audit accessibility, SEO, performance, and best practices.
- **W3C Nu HTML Checker:** Validate HTML markup.
- **W3C CSS Validation Service:** Check CSS syntax.
- **Keyboard testing:** Navigate through the website without using a mouse.
- **Responsive testing:** Verify the layout using browser developer tools.
- **Browser console:** Check for JavaScript errors and missing resources.

Lighthouse targets should be confirmed after running the audits; scores may vary depending on the implementation and testing environment.
